# مشجرة أنساب العرب

مرجع تفاعلي عربي لعرض أنساب العرب بمستويين للقراءة: صورة عامة مبسطة، ومشجرة تفصيلية تتوسع في طبقات الأصول والفروع مع بيان مواضع الخلاف.

## الأقسام
- الصورة العامة
- العرب البائدة
- العرب العاربة — القحطانيون
- العرب المستعربة — العدنانيون
- قريش
- النسب النبوي
- مصطلحات وطبقات النسب
- دليل القبائل والأعلام
- منهج التحقيق
- مواضع الخلاف والمراجع

## دليل القبائل والأعلام
دليل قابل للبحث يربط أسماء القبائل والفروع والأعلام بالمشجرة، ويعرض ما أمكن توثيقه من السياق النسبي والتاريخي والجغرافي، مع إبقاء المعلومات المختلف فيها أو غير الكافية للجزم موسومة بوضوح.
